# 🐍 Hydra-Wordlister

> Ferramenta de força bruta altamente direcionada para criação de wordlists baseadas em engenharia social, usando permutações e mutações de caracteres.

---

## 📌 Sobre o Projeto
O **Hydra-Wordlister** foi desenvolvido para auxiliar profissionais de segurança da informação e pentesters a gerarem dicionários de senhas altamente customizados. Diferente de geradores tradicionais, ele foca em padrões específicos de alvos, aplicando regras inteligentes de permutação e mutação para maximizar a eficácia em testes de intrusão.

---

## ⚙️ Funcionalidades
- 🔀 **Permutação Avançada:** Combinação inteligente de termos-chave, nomes, datas e sufixos.
- 🧬 **Mutação de Caracteres:** Aplicação de variações deleet, leetspeak e trocas comuns de símbolos.
- 🎯 **Foco em Engenharia Social:** Ideal para ataques baseados em informações coletadas via OSINT do alvo.
- 🚀 **Alta Performance:** Geração rápida e estruturada de arquivos de saída prontos para uso em ferramentas como Hydra, Hashcat ou Burp Suite.
